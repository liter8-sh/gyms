# gyms

**The issue tracker for the [liter8.sh](https://liter8.sh) gyms.**

The verse is eighteen gyms, each in its own repository — but reports live
here, in one tracker, so nothing gets lost across eighteen of them. If
something in a gym is wrong, or a gym should do something it does not, this
is where to say so.

## Reporting

[Open an issue](https://github.com/liter8-sh/gyms/issues/new) and name the
gym in the title — `run: heap diagram loses an array after concat` gets
fixed faster than `bug`.

The report that gets fixed fastest says:

- **which gym** — `run`, `vim`, `sql`, …; `liter8` for the hub,
  `learn-storage` for the sync server
- **what you did** — the exercise or page, the program or input if it matters
- **what you expected**, and **what it did instead**
- **where** — browser and OS; for a grading bug, the step number helps

Bugs, feature requests and content corrections all take the same form — a
wrong decoy reason, an unfair par and a typo are all worth a report.

## The gyms

Each serves at `<slug>.liter8.sh`, grouped by roadmap stage:

| Stage | Gyms |
|---|---|
| The floor | `run` · `shell` · `git` · `regex` · `vim` |
| Reading | `review` · `test` |
| Data | `sql` · `schema` |
| The wire and the machine | `net` · `linux` · `concurrency` |
| Shipping | `container` · `infra` · `deploy` |
| Operating | `system-design` · `secure` · `debug` |

`liter8` is the hub itself, `learn-core` the engine the gyms are built on,
`learn-storage` the optional sync server you can run yourself.

## Not a gym issue

Anything else — the org, a question, something you would rather not post
publicly — `amirkode` on GitHub.
